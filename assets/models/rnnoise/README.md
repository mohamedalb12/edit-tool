RNNoise models for FFmpeg's `arnndn` filter (neural speech denoising).

- `sh.rnnn` — "somnolent-hogwash": speech, trained on recording noise (GregorR/rnnoise-models; the models are
  stated there not to be subject to copyright). The default for voice clean-up.
- `std.rnnn` — the model bundled with Xiph's RNNoise (BSD-3-Clause, Copyright Xiph.Org Foundation / Mozilla).

Source: https://github.com/richardpl/arnndn-models · https://github.com/GregorR/rnnoise-models · https://github.com/xiph/rnnoise
